# Transformer PDF Question Answering System

A Transformer-based project for working with questions and answers from uploaded PDF documents.

## Planned Features

- Upload and process PDF documents
- Ask user-defined questions based on PDF content
- Generate/suggest questions from PDF content
- Study and compare suitable Transformer architectures
- Explore extractive and abstractive/generative approaches

## Current Status

Research and architecture selection phase.

We are currently studying different Transformer architectures and models
before finalizing the implementation.
